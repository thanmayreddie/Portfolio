# Thanmay Teja Reddy Anireddy — Portfolio

A responsive, futuristic personal portfolio built with HTML, CSS and vanilla JavaScript.

## Features

- Responsive layout
- Dark futuristic visual system
- Scroll progress indicator
- Scroll reveal animations
- Mobile navigation
- Back-to-top button
- Interactive hover states
- Accessible semantic structure
- Featured Wanderlust project
- Skills, experience, education, DSA progress and contact sections

## Run locally

Open `index.html` in a browser, or use the VS Code Live Server extension.

## Before deploying

1. Replace the profile placeholder in the hero with your real photo.
2. Add your latest resume as `assets/Thanmay-Teja-Reddy-Resume.pdf`.
3. Replace generic GitHub profile links on individual projects with the exact repository URLs when available.
4. Add internship certificate files/links if you want them displayed publicly.

## Suggested deployment

GitHub Pages, Vercel, or Render can host this static site.
